## Definition

The **Cybersecurity Threat Landscape** refers to the collection of existing, evolving, and emerging cyberthreats that target computer systems, networks, applications, and data.

It represents the **current state of cyber risks** including:
- Threat Actors
- Attack Techniques
- Vulnerabilities
- Impacted aspects

## Threat Actors

| Actor Type | Description | Motivation |
|---|---|---|
| **Cyber Criminals** | Financially motivated hackers | Money, data theft |
| **Hacktivists** | Hack for political/social causes | Ideology, attention |
| **Nation-State Attackers** | Government-sponsored hackers | Espionage, warfare |
| **Insiders** | Employees/contractors with access | Revenge, money |
| **Script Kiddies** | Unskilled users of existing tools | Fame, curiosity |

## Common Cyber Threats

### 1. Phishing
Tricking users into revealing sensitive information through **fake emails, websites, or messages**.
- **Spear Phishing** — targeted at specific individuals
- **Vishing** — via voice calls

### 2. Malware
Malicious software designed to **damage or disrupt** systems.
Includes: Viruses, Worms, Ransomware, Spyware, Trojans
> See: [[Malware Types]]

### 3. DoS / DDoS Attacks
Attackers **overwhelm systems with traffic** making services unavailable.
- **DoS** — single source
- **DDoS** — distributed sources (botnet)

### 4. Web Application Attacks
- SQL Injection
- Cross-Site Scripting (XSS)
- CSRF

### 5. Network Attacks
- **MITM** (Man in the Middle)
- **ARP Spoofing**

> 💡 **Difference: Snooping vs Spoofing**
> - **Snooping** = passive eavesdropping (masquerading, active)
> - **Spoofing** = impersonating another system/user

---

## Attack Vectors

Paths or methods used by attackers to gain access to a target:

1. **Email** — phishing, malware attachments
2. **Web Applications** — SQL injection, XSS
3. **Removable Media** — infected USB drives
4. **Social Engineering** — human manipulation
5. **Insider Threats** — abuse of legitimate access

---

## Vulnerabilities

Common weaknesses attackers exploit:

1. **Outdated/Unpatched Systems** — missing security updates
2. **Misconfigured Firewalls/Servers** — open ports, weak rules
3. **Weak Authentication Mechanisms** — simple passwords
4. **Poor Coding Practices** — insecure development
5. **Lack of Security Awareness** — employees as weak links

---

## Emerging Threats

| Threat | Description |
|---|---|
| **Zero-Day Attacks** | Exploiting unknown vulnerabilities before patches exist |
| **IoT/OT Attacks** | Targeting Internet of Things devices |
| **AI-Powered Cyber Attacks** | Using AI to automate and improve attacks |
| **Cloud Security Threats** | Misconfigurations in cloud environments |
| **Supply Chain Attacks** | Targeting software vendors to reach end customers |
| **Ransomware as a Service (RaaS)** | Ransomware sold/rented to other criminals |

| Impact Type | Description |
|---|---|

| **Financial Losses** | Direct theft, fines, recovery costs |
| **Data Breaches & Privacy Violations** | Exposure of sensitive data |
