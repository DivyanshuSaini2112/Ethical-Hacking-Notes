# 🧠 Skills Required for Ethical Hacking

> **MOC:** [[MOC - Ethical Hacking Fundamentals]] | **Tags:** `#ethical-hacking` `#skills`

---

## Core Technical Skills

| Skill | Why It Matters |
|---|---|
| **Networking Knowledge** | Understanding TCP/IP, protocols, routing — foundation of all hacking |
| **OS Proficiency** | Linux (primary), Windows, macOS — knowing the environment you're attacking |
| **DBMS** | SQL knowledge for database attacks and injection testing |
| **Web App Security** | Understanding how web apps work to find vulnerabilities |
| **Cryptography** | Encryption/decryption, understanding secure communications |
| **Mastery of Security Tools** | Nmap, Metasploit, Wireshark, Burp Suite |
| **Cloud Security** | AWS, Azure, GCP — modern infrastructure skills |
| **Programming & Scripting** | Python, Bash, PowerShell for automation and exploit writing |

---

## Networking Knowledge (Deep Dive)

Must know:
- OSI and TCP/IP models
- Common protocols: HTTP, HTTPS, FTP, SSH, DNS, SMTP, SNMP
- Subnetting, VLANs, routing
- Firewalls, IDS/IPS concepts

> Connects to: [[Scanning in Ethical Hacking]], [[SNMP Enumeration]], [[Types of Port Scans]]

---

## OS Proficiency

**Linux** (most important):
- Command line mastery
- File permissions (`chmod`, `chown`)
- Process management
- Package management

**Windows:**
- Active Directory
- Registry
- PowerShell

---

## Programming & Scripting

| Language | Use in Ethical Hacking |
|---|---|
| Python | Exploit scripts, tool automation, OSINT scripts |
| Bash | Linux automation, quick recon scripts |
| PowerShell | Windows exploitation, post-exploitation |
| JavaScript | XSS payload crafting |
| SQL | SQL injection testing |

---

## Soft Skills

- **Problem solving** — creative thinking to find non-obvious vulnerabilities
- **Report writing** — communicating findings to non-technical stakeholders
- **Ethics & integrity** — staying within scope, not disclosing findings
- **Continuous learning** — the threat landscape evolves constantly

| Certification | Focus |
|---|---|
| CEH (Certified Ethical Hacker) | Broad ethical hacking coverage |
| OSCP | Hands-on penetration testing |
| CompTIA Security+ | Foundational security knowledge |
| CISSP | Management-level security |
| eJPT | Entry-level penetration testing |
